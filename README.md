# whoisspy

WhoIsSpy is a party word game for friends in the same room. Everyone gets a secret word, but the spy gets a different word (or none). Take turns describing your word, then vote out the spy.

Play: https://daewoogao.github.io/whoisspy/

- `index.html`: club version. One person creates a club, everyone joins with the code on their own phone. Phones connect directly to the host phone through the free PeerJS service.
- `one-phone.html`: pass-the-phone version for a single phone.
- `peerjs.min.js`: PeerJS 1.5.4 (MIT license, see `peerjs.LICENSE`).

Word pairs come in English and Chinese, tagged by the language they work in.
